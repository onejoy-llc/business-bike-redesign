# ビジネスバイクGoGo リニューアルサイト

## 起動のしかた

1. ターミナルでこのフォルダに移動します
   例）`cd ~/business-bike-redesign`
2. サーバーを起動します
   例）`node server.js`
3. ブラウザで開きます
   - サイト：http://localhost:3000/
   - 管理画面：http://localhost:3000/admin/

※ ポート番号を変える場合：`PORT=8080 node server.js`
※ Node.js 18以上が必要です（追加のインストールは不要）

## 管理画面の使い方

1. 管理画面を開き、パスワードでログインします
   - 初期パスワード：`atoz-admin`
   - **最初に「パスワード変更」から必ず変更してください**
2. 左のメニューから編集したい項目を選びます
   例）休業のお知らせを出す →「基本情報」→「お知らせ文」に入力
3. 右上の「保存する」を押すとサイトに反映されます（Ctrl / ⌘ + S でも保存できます）
4. 「ページを確認」で実際の表示を確認できます

### 編集できる内容

| メニュー | 内容 |
|---|---|
| 予約一覧 | Web予約の受付内容。対応状況（新規/対応中/完了）・社内メモ・CSV出力 |
| お問い合わせ一覧 | お問い合わせフォームの受付内容 |
| 基本情報 | お知らせバナー、店名、電話番号、営業時間、住所、SEO設定、関連リンク |
| トップページ | 大見出し、リード文、写真3枚、数字のポイント |
| 車種・料金 | 車種の追加・削除・並び替え、写真、料金プラン、料金表の注記 |
| ご利用案内 / サービス概要 / よくある質問 / 会社概要 | 各ページの文章 |
| 予約・問い合わせ設定 | フォームの説明文、台数・付属品の選択肢、完了メッセージ |
| 貸渡約款 / 個人情報保護方針 | 本文（行頭「## 」で見出し、「### 」で小見出し） |

## フォルダ構成

```
server.js        サーバー本体
views.js         各ページのHTMLテンプレート
public/          CSS・JS・画像（public/uploads に管理画面からの画像が入ります）
admin/           管理画面
data/
  content.json       サイトの文章・料金などすべての内容
  reservations.json  Web予約の受付データ
  contacts.json      お問い合わせの受付データ
  admin.json         管理画面のパスワード（暗号化済み）
  backups/           保存のたびに直前の content.json を自動バックアップ（最新20件）
```

## 旧サイトからの引き継ぎ

- 旧URL（/cartypeprice/〜）は新しい車種ページへ自動転送（301）されます
- /howto/ /price/ /service/ /faq/ /shop/ /contact/ /company/ /covenant/ /privacy/ /reservation/ は同じURLのままです

## 公開前に必要な作業

- 予約・お問い合わせの**メール通知**は未設定です（現在は管理画面で確認）。公開サーバーに合わせて設定が必要です
- 公開時は HTTPS 環境で運用してください
- `data/` フォルダは定期的にバックアップしてください

## GitHub Pages（デザイン確認用サイト）

- `main` ブランチに push すると、GitHub Actions が `build-static.js` で全ページを静的HTMLに書き出し、GitHub Pages に自動公開します
- 確認用サイトでは **予約・お問い合わせの送信と管理画面は動作しません**（表示のみ）
- 検索エンジンには載らない設定（noindex）にしています
- 管理画面で内容を変更した場合は、`data/content.json` と `public/uploads/` をコミットして push すると確認用サイトにも反映されます
- 手元で書き出しを試す場合：`BASE=/business-bike-redesign node build-static.js`（`dist/` に出力）

## 車種画像について

- 車種画像はメーカー公式サイトの画像（白背景）を、同じ形式（1200×900・白背景・接地位置をそろえる）に加工して使っています
  - ホンダ：ジャイロキャノピー／ジャイロX／スーパーカブ50プロ（honda.co.jp 製品ページ）、ジャイロアップ（Honda ニュースリリース 1985年）、ズーマー（honda.co.jp 旧製品ページ）
  - ヤマハ：ギア（yamaha-motor.co.jp 製品ページ）、マジェスティ250（ヤマハ発動機 ニュースリリース 2011年・2009年）
  - 業務用電動アシスト3輪車・業務用2輪車：メーカー不明のため自社撮影写真を同じ形式に加工
- **メーカー画像の使用には、各メーカーまたは販売店への使用許諾の確認をおすすめします**
- 新しい画像を同じ形式にする場合（Mac）：`swift tools/normalize-bike-image.swift 入力画像 出力.jpg`
